Техническое задание
1. Общие сведения:
Приложение «КриптоСыч» — учебное приложение, показывающее текущие курсы криптовалют к доллару США. 
Источник данных — открытый API CoinGecko.

2. Функциональные требования:
Отображение курсов 5 самых популярных валют: Bitcoin, Ethereum, Solana, Dogecoin, Binance.
Для каждой монеты нужно указать: 
- название, 
- цену в USD, 
- изменение курса за послпедние 24 ч в % (рост — зелёным, падение — красным)
Ручное обновление кнопкой «Обновить курсы».
Автоматическое обновление раз в 30 секунд.
Приложение не должно падать при ошибках сети.

3. Требования к интерфейсу:
- окно размером 500×300; 
- элементы: заголовок, пять строк курсов, строка статуса, кнопка
- в левом верхнем углу - логотип приложения
